# HumanGateway 0.1.0

**Release date:** 2026-09-04

## Summary

HumanGateway 0.1.0 delivers an offline-first communication fabric for durable human messages, workflow tasks, and artifacts. It includes a local Edge Gateway, a PostgreSQL-backed Relay, an offline PWA, shared protocol schemas, synchronization, security, and a FlowForge provider contract.

## Highlights

- Durable SQLite/WAL Edge storage and local filesystem artifact storage.
- Cursor-based, idempotent Edge-to-Relay synchronization with retries and acknowledgements.
- PostgreSQL Relay storage, gateway registration, rendezvous routing, and remote access surfaces.
- Content-addressed, hash-verified, deduplicated, resumable artifact transfer.
- Authenticated local and remote users with per-resource authorization.
- React/TypeScript PWA with Service Worker caching, IndexedDB outbox, messaging, tasks, and delivery status.
- FlowForge `human-input` and `human-approval` provider mapping, correlation, expiry handling, and headless harness.
- Docker Compose development stack and Raspberry Pi/old-PC Edge packaging.

## Compatibility and Prerequisites

- .NET 10 SDK/runtime.
- Node.js 20+ and npm for the client and workflow package.
- Docker or Podman for the Compose deployment.
- PostgreSQL for Relay operation.
- Current Chrome, Edge, Firefox, or Safari for the PWA.

## Known Limitations

- Delivery is eventual and asynchronous, not real-time chat.
- The Edge requires a later outbound sync opportunity for remote delivery and acknowledgements.
- Live end-to-end testing against a real FlowForge runtime is out of scope; the workflow package is validated against a published interface contract and an in-repository stub.
- No SMS, USSD, WhatsApp, or email adapters are included.
- HumanGateway does not provide workflow execution, consumer role authorization, or the consumer’s audit trail.
- The default Relay artifact store uses PostgreSQL BYTEA; an external object-store adapter is future work.
- No telemetry or analytics are included by default.

## Validation

The repository includes .NET unit/integration tests, PWA Vitest tests, workflow package tests, crash-consistency coverage, and synchronization/chaos coverage. Run the applicable commands from the repository README; Docker-dependent Relay tests require a Docker-compatible socket.

## Security and Privacy

Production Edge-to-Relay traffic must use TLS. Keep bootstrap credentials, gateway tokens, database credentials, and signing secrets outside source control. Deployers control retention and compliance obligations for message, task, conversation, and artifact data.
